### 1.2 项目简介（四种长度，按场合直接取用）


#### （1）一句话版（约 25 字，用于标题、封底、名片）

让农田与林子里的有益生物"看得见、算得清、管得住"。


#### （2）摘要版（约 110 字，用于报名表、路演开场）

益望是一套面向农林有益生物（传粉昆虫、捕食性与寄生性天敌、食虫鸟类）的多模态智能监测与生态服务决策系统。它用声学、视觉与环境传感器自动识别并连续观测有益生物，把生物群落状态换算为授粉、害虫调控等生态服务的功能量与经济价值，并给出减药、释放天敌、配置蜜源植物等可执行的田间调控建议。


#### （3）标准版（约 350 字，用于商业计划书摘要页、PPT 第二页）

害虫监测已经相当成熟——虫情测报灯、孢子捕捉仪、昆虫雷达都在盯着有害生物；但真正决定产量与生态安全的"有益生物"，至今仍几乎完全依赖人工样方与目测调查，成本高、频次低、覆盖小、误差大。后果有两层：一是授粉不足与天敌不足无法被及时发现，减产与虫害暴发只能事后补救；二是授粉、生物防治这些"生态服务"的价值无法被计量，保护生态的人拿不到经济回报，绿色生产也缺少可交易、可审计的凭证。

益望提出以"跨模态观测一致性"为核心的多模态融合方法，把声学（昆虫飞行声、鸟鸣、蜂群声）、视觉（访花昆虫、黄板、红外相机）与环境微气象等异构信号在同一生物事件上做一致性校验与置信度融合；在此基础上建立"有益生物群落—生境—管理措施 → 生态服务功能量 → 经济价值"的可标定供给函数；最后在"增产、减药、保生物多样性、控成本"的多目标约束下求解可执行的调控决策。产品由边缘监测节点、云平台与手机端组成，目标是让生态服务第一次成为可测量、可核算、可审计的数据产品。


#### （4）详版（约 700 字，用于申报书立项背景首段）

在乡村振兴与绿色发展的国家战略背景下，"减药增效"与"生态产品价值实现"同时被推到了前台：一边是农药化肥减量增效与绿色防控的硬任务，另一边是生态补偿、生态系统生产总值（GEP）核算、生态产品价值实现机制的落地需求。两者交汇的地方，正是本项目要回答的问题——我们能不能把"有益生物"这件事，从模糊的经验判断，变成可测量、可核算的数据？

当前农林监测体系存在一个结构性偏斜：虫情测报灯、孢子捕捉仪、昆虫雷达这些自动化装备监测的全是有害生物；而传粉昆虫、捕食性与寄生性天敌、食虫鸟类这些"帮手"，仍只能靠人工扫网、样方与专家形态鉴定——测不准、测不起、测不勤，且数据无法横向比较。

数据链条的下游同样断裂。现有的生态服务价值核算，多采用"土地面积 × 当量因子 × 单价"的静态估算方法，与实际生物实况完全脱钩——同一片地，无论天敌多少、传粉者多少，核算出来的生态服务价值是一样的。这让保护生态的人得不到经济回报，也让生态补偿缺乏差异化依据。

益望的核心贡献，是提出以"跨模态观测一致性"为度量的多模态融合方法，并建立从生物实况到生态服务价值的可标定供给函数，使生态服务核算第一次具备实测输入、不确定度与可审计性。技术上采用"通用能力用成熟开源模型、创新火力集中于有益生物监测与服务核算"的策略，保证工程可靠性与研究先进性的平衡。产品已在【待填：完成情况】阶段，实测可在【待填：场景】实现主要功能群识别 F1 达【待填】，服务价值核算不确定度控制在【待填】以内。

## 第二章  项目背景与痛点

本章对应商业计划书的"痛点与市场机会"章节、PPT 的第 2–3 页。写作要求：每一条痛点后面必须跟一个数字或一个可复现的失败案例，禁止只使用形容词。


### 2.1 背景：三浪叠加

本项目处在三股浪潮的交汇点上，它们共同放大了"有益生物看不见、生态服务算不清"这个问题的严重性。

- 第一浪·绿色发展成为硬约束。农药化肥减量增效、绿色防控、生物防治推广被写入各级考核；生态补偿、生态系统生产总值（GEP）核算、生态产品价值实现机制在多地试点推开；生物多样性保护纳入国家战略。这些任务的共同前提是——要有关于生物的数据。

- 第二浪·边缘 AI 与低功耗感知成熟。声音事件识别、轻量目标检测已经过了"能用"的门槛；带 NPU 的边缘计算芯片（如瑞芯微 RK3576/RK3588、NVIDIA Jetson 系列）成本持续下探；太阳能 + 锂电 + LoRa/4G 的低功耗节点方案成熟。这意味着一套"田间连续自主观测"的系统第一次具备了工程可行性。

- 第三浪·生态产品价值实现机制兴起。生态服务从"公益概念"走向"可交易资产"：绿色与有机认证、农业指数保险、生物多样性金融工具都在寻找客观、可审计的底层数据。谁提供这层数据，谁就掌握了这条价值链的入口。

三浪叠加的结果是：关于有益生物与生态服务的数据需求在快速释放，而对应的自动化监测与核算工具供给几乎为零。


### 2.2 痛点一：监测体系"只盯害虫，不看益虫"

这是本项目最根本的立足点。当前农林监测的自动化装备，几乎全部服务于有害生物：

| 监测装备 | 监测对象 | 技术形态 | 是否有益生物 |
|---|---|---|---|
| 自动虫情测报灯 | 趋光性害虫 | 诱捕 + 自动拍照 + 图像识别 | 无（且会误杀） |
| 孢子捕捉仪 | 病原孢子 | 气流捕捉 + 显微成像 | 无 |
| 性诱捕器 | 特定害虫成虫 | 性信息素诱芯 + 计数 | 无 |
| 昆虫雷达 | 迁飞性害虫 | 雷达回波，科研级装备 | 无 |
| 黄板 / 蓝板 | 蓟马、粉虱、蚜虫（兼诱杀） | 人工查看或人工拍照 | 无（且会误杀） |
| 有益生物 | 传粉昆虫、天敌、食虫鸟类 | 人工扫网、样方、目测、专家鉴定 | ★ 唯一的监测手段是人工 |

这个偏斜带来一个可以被现场证实的失败案例：诱虫灯与黄板本身无差别杀伤有益昆虫。由于没有任何系统在监测有益生物，也就无法评估"绿色防控措施是否真的保护了天敌"、"大规模诱杀是否误伤了传粉者"。这是一个**花了钱做绿色防控、却拿不出证据**的普遍困境。

证据形态与采集方法：在绿色防控示范区做诱虫灯/黄板诱集物的分类统计，拍照记录其中天敌与传粉者的占比。这一组照片是答辩第 2 页最有冲击力的素材，且成本极低、一天即可完成。


### 2.3 痛点二：人工调查"测不准、测不起、测不勤"

有益生物目前唯一的监测手段是人工调查，而人工调查存在四个无法通过增加人力来解决的结构性缺陷：

| 缺陷 | 具体表现 | 后果 |
|---|---|---|
| 测不准 | 寄生蜂、食蚜蝇、野生蜂等类群形态鉴定门槛高，严重依赖分类学专家；不同调查员之间的判定差异大 | 数据缺少一致性与可比性 |
| 测不起 | 单次样方调查需要专业人员现场作业，人力成本高；诱集物带回实验室分类鉴定的周期长 | 监测无法规模化铺设 |
| 测不勤 | 年调查频次通常只有几次，且受农忙、天气、人员安排限制 | ★ 恰好错过授粉临界期与害虫—天敌消长的关键窗口 |
| 不可比 | 不同人、不同方法、不同空间尺度采集的数据无法横向比较 | 无法形成区域尺度的趋势判断 |

核心结论：**没有连续、标准化、可追溯的有益生物数据，生态服务核算就没有可信的输入。** 这是整条"生态产品价值实现"链条上最前端、也最致命的断点。


### 2.4 痛点三：生态服务"算不清"——保护生态缺少经济回报

这是本项目最具产业价值的一层痛点，因为它直接解释了"为什么明知有益生物重要，却没有人愿意为它投入"。

现有的生态服务价值核算，主流方法是当量因子法：以土地面积乘以不同类型的生态服务价值当量，再乘以单价。这个方法的问题不在于公式，而在于**输入与生物实况完全脱钩**——同一片地，无论天敌数量多少、传粉者是否充足、群落结构是否健康，核算出来的生态服务价值完全相同。

| 环节 | 现状 | 造成的后果 |
|---|---|---|
| 数据输入 | 按土地面积与地类查表取当量，不含任何生物实测数据 | 核算结果与实际生态状况无关 |
| 授粉服务 | 以作物面积估算，不区分传粉者是否充足 | 授粉不足的减产风险被掩盖 |
| 害虫调控 | 以地类估算，不区分天敌与害虫的比例 | 天敌崩溃无法预警，生物防治的成效无法证明 |
| 价值出口 | 核算结果仅用于报告，缺少可审计的过程与不确定度 | 无法作为生态补偿、认证、保险的定价依据 |

后果是双向的：对生产者的保护行为（留花带、少打药、释放天敌）没有经济回报，"保护无收益"；对管理者而言，生态补偿只能"撒胡椒面"，无法差异化投放；对金融市场而言，缺少可核验的底层数据，绿色认证与指数保险都难以精确定价。

因此本项目要回答的，不是"要不要保护有益生物"（这是共识），而是**"如何让有益生物的生态服务变成一个可测量、可核算、可审计的量"**。这就是科学问题的来源。
